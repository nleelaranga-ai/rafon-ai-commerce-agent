# RAFON AI — Autonomous Commerce Intelligence Platform

Built for **Razorpay AI Buildathon 2026** (AI Growth & Agentic Commerce Track).

## Overview

RAFON AI is an AI-powered commerce agent that helps merchants increase revenue through conversational shopping, intelligent product recommendations, AI-powered upselling, explainable payment decisions, and Razorpay checkout integration.

## Core Features

* AI Shopping Assistant
* Smart Product Recommendations
* AI Upsell & Cross-sell Engine
* Razorpay Test Mode Checkout
* Payment Failure Recovery
* Merchant Revenue Analytics
* Explainable Audit Timeline

## Tech Stack

| Layer      | Technology                         |
| ---------- | ---------------------------------- |
| Frontend   | Next.js + Tailwind CSS + Shadcn UI |
| Backend    | FastAPI                            |
| AI         | Google Gemini 2.5 Flash            |
| Payments   | Razorpay Test Mode APIs            |
| Database   | SQLite                             |
| Charts     | Recharts                           |
| Deployment | Vercel + Render                    |
